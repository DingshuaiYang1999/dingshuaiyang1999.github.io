Path-planning visualizer

A robot has to find a way around obstacles. Here you draw walls, mark a start and a goal, and watch different search methods look for a route, one step at a time.

Try this

  • Press Run and watch the search grow. Then drag the green S or the red G to new places and run it again.
  • Draw a wall across the middle with Draw rectangle and leave only a small gap. Which method finds the gap fastest?
  • Switch between RRT, Bidirectional RRT and PRM, or turn the speed to “instant” to compare results.

The same ideas are in my Python code (GitHub, opens in a new tab), re-implemented here in JavaScript so you can play with them. The technical details of each method are in the “How it works” section below the map.
