Neural-network playground: learning a decision boundary

A neural network is a function with many adjustable numbers. Here it learns, from examples, to say whether a spot on the plane is blue or orange. The background shows its current answer everywhere, and it improves while you watch.

Try this

  • Training starts by itself. Watch the background change from grey to a clear boundary, and the loss curve fall.
  • Click or tap the field to add points while it trains. The boundary adapts to each new point.
  • Choose Spiral and remove all hidden layers. A straight line cannot separate the arms; then add layers and neurons until it can.
  • Choose Overfit me: the training loss falls while the dashed test loss rises. Then raise Regularisation and see the boundary become smoother.
  • Pick a challenge, for example the circle with as few neurons as possible.
How it works (technical details)

Model

The input is a point x = (x₁, x₂) in [−1, 1]². Layer l (with h(0) = x) computes

z(l) = W(l) h(l−1) + b(l),   h(l) = φ(z(l))

and the last layer has one unit with a sigmoid, so that the output ŷ = σ(z) is the estimated probability of the orange class:

σ(z) = 1 / (1 + e−z)

The hidden activation φ is ReLU, φ(z) = max(0, z), tanh, or the sigmoid. Without a hidden layer the model is logistic regression, whose decision boundary {ŷ = 0.5} is a straight line. With hidden layers, ReLU produces a piecewise-linear boundary and tanh or sigmoid a smooth one. A network with one sufficiently wide hidden layer can approximate any continuous decision boundary on a bounded region (universal approximation theorem); depth often achieves the same shape with fewer neurons.

Loss

With labels y ∈ {0, 1} the training loss is the binary cross-entropy plus an optional L2 penalty on the weights:

L = −(1/N) Σ [ y log ŷ + (1 − y) log(1 − ŷ) ] + (λ/2) Σ W²

A network that always answers 0.5 has loss ln 2 ≈ 0.693, the dotted “chance level” in the loss plot. The plot shows the data term only, for the training points (solid) and, where available, for held-out test points (dashed).

Back-propagation

For a sigmoid output with cross-entropy the error at the output is δ(L) = ŷ − y. It is propagated backwards with the chain rule:

δ(l) = ( W(l+1)ᵀ δ(l+1) ) ⊙ φ′(z(l)),   ∂L/∂W(l) = δ(l) h(l−1)ᵀ,   ∂L/∂b(l) = δ(l)

with φ′(z) = 1 − tanh²(z) for tanh, σ(z)(1 − σ(z)) for the sigmoid, and 1 for z > 0 (otherwise 0) for ReLU.

Optimisation

One epoch is one pass over all training points in random order, in mini-batches of 10. After each mini-batch the parameters θ are updated with the averaged gradient g and the learning rate η. SGD with momentum uses v ← 0.9 v − η g and θ ← θ + v. Adam keeps running averages of the gradient m and of its square s, with bias correction:

m ← β₁m + (1 − β₁)g,   s ← β₂s + (1 − β₂)g²,   θ ← θ − η · m̂ / (√ŝ + ε)

(β₁ = 0.9, β₂ = 0.999, ε = 10⁻⁸). Weights are initialised from a normal distribution with variance 2/nin for ReLU layers (He) and 1/nin otherwise; biases start at zero. Each reset draws new random weights, which is why two runs of the same network can behave differently.

Overfitting and regularisation

A network with many parameters can fit the noise in a small training set. The training loss then keeps falling while the loss on unseen test points rises. The “Overfit me” data set has 30 training points, 10 % of them with a wrong label, and a test set of 90 points. An L2 penalty λ shrinks the weights and limits how sharply the boundary can bend.

Reading the picture

  • Field: ŷ is evaluated on a 44 × 44 grid and drawn smoothed; blue means P(orange) near 0, orange near 1, neutral near 0.5. Filled marks are training points, hollow marks are test points.
  • Diagram: each small square is the output of one neuron over the plane (scaled per neuron). Line thickness is |w|, scaled to the largest weight; solid purple lines are positive weights, dashed green lines are negative weights.
  • Challenges count the accuracy over all points of the fixed data set and stop when it reaches 95 %.
