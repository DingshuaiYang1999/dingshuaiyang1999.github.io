Edge detection: Sobel x, Sobel y and Canny

An edge is a place where a picture changes quickly from dark to light. This page shows how a computer finds edges, step by step, and updates the result while you move the sliders.

Try this

  • Watch the demo play once, then drag Blur upwards: the noise disappears, but so do the fine details.
  • Lower the two thresholds: more and more faint edges appear. Raise them and only the strongest outlines remain.
  • Compare Sobel x and Sobel y: the first finds up-and-down lines, such as the sides of the head; the second finds side-to-side lines.
  • Switch on Show the Canny steps to see how thick edges are thinned and how faint pieces are kept only when they join a strong edge.
How it works (technical details)

Pipeline

  1. Grayscale: I = 0.299 R + 0.587 G + 0.114 B (the weights used by cv2.cvtColor).
  2. Gaussian blur with kernel size k and standard deviation σ suppresses noise. The kernel is separable: G(x) ∝ exp(−x² / 2σ²), applied to rows and then columns, with mirrored borders (cv2.GaussianBlur).
  3. Sobel approximates the image derivative with 3 × 3 kernels that also smooth across the derivative direction.
  4. Non-maximum suppression thins the edges to one pixel.
  5. Double threshold and hysteresis keep strong edges and the weak edges connected to them.

Sobel kernels

Gx = [ −1 0 +1 ; −2 0 +2 ; −1 0 +1 ] ∗ I    Gy = [ −1 −2 −1 ; 0 0 0 ; +1 +2 +1 ] ∗ I

Sobel x (Gx) is the horizontal derivative: it responds to brightness changes from left to right and therefore highlights vertical edges. Sobel y (Gy) is the vertical derivative and highlights horizontal edges. Each is signed (dark-to-bright positive, bright-to-dark negative); the panels show |G| by default, and the option “Show Sobel as signed” maps zero to mid-gray. Both panels use the same scale so that they can be compared.

Gradient magnitude and direction

|G| = √(Gx² + Gy²)  (L2)  or  |G| ≈ |Gx| + |Gy|  (L1)    θ = atan2(Gy, Gx)

The magnitude image shows edges of every orientation but they are several pixels wide, and a single global threshold on it either keeps noise or breaks contours. OpenCV’s default is L1; L2gradient=True selects L2. The setting above changes the units of the thresholds: with L2 the thresholds are compared against |G|².

Canny

  • Non-maximum suppression: θ is rounded to one of four directions (horizontal, vertical, two diagonals). A pixel survives only if its magnitude is larger than that of its two neighbours along θ. This is why Canny edges are one pixel wide, unlike Sobel.
  • Double threshold: pixels with |G| > high are strong, pixels between low and high are weak, and the rest are discarded.
  • Hysteresis: a weak pixel is kept only if it is 8-connected, through other weak or strong pixels, to a strong pixel. Isolated faint responses (noise) disappear, while faint continuations of real contours are kept.

Sobel versus Canny in short

Sobel is a filter: it outputs a continuous edge-strength image in one direction (x or y) or in combination. Canny is a complete detector: it uses the Sobel gradients, but outputs a binary map of thin, connected edges, controlled by blur and two thresholds.

OpenCV equivalents

cv2.GaussianBlur(gray, (k, k), sigma) → cv2.Sobel(blur, cv2.CV_16S, 1, 0) / (…, 0, 1) → cv2.Canny(blur, low, high, L2gradient=…)

cv2.Canny does not blur by itself. The JavaScript code here follows the same steps and the same comparison rules as OpenCV, and the repository’s Python script checks a NumPy version against cv2.Canny pixel by pixel. Reference code: edge detection in Python (GitHub, opens in a new tab).

Reading the panels

Bright pixels mark where the picture changes quickly. Sobel x and Sobel y each look in one direction only; their combination is the gradient magnitude; Canny turns that magnitude into thin black-and-white outlines.
