k-Nearest Neighbours: guess a colour from its neighbours

The coloured dots are examples whose colour is already known. Move the pointer over the picture, or tap it, and the computer guesses the colour of that spot by asking the closest dots to vote.

Try this

  • Pick a colour and click or tap an empty spot to add dots. Drag any dot to move it: the coloured background changes immediately.
  • Slide k from 1 to 15. A small k follows every single dot; a larger k gives a smoother, more cautious guess.
  • Press Mix up some labels while k is 1, then raise k to see how a larger k ignores a few wrong dots.
  • Load Two moons or Three-arm spiral and look for the k that separates the shapes best.
How it works (technical details)

Algorithm

k-NN is a non-parametric, instance-based classifier. “Training” stores the labelled points. To classify a query point q it

  1. computes the distance from q to every stored point (brute force, O(n) per query),
  2. selects the k points with the smallest distances, and
  3. predicts the class with the most votes among them.

Distance metrics

Euclidean (L2): d(a, b) = √( (a₁ − b₁)² + (a₂ − b₂)² )

Manhattan (L1): d(a, b) = |a₁ − b₁| + |a₂ − b₂|

The metric changes which points count as “near”: L2 neighbourhoods are circles, L1 neighbourhoods are diamonds. The dashed outline in the demo is the L2 circle or L1 diamond that just reaches the k-th neighbour.

Ties

If several classes receive the same number of votes, the class that contains the single nearest of the tied points wins. Equal distances are resolved by the older point. This rule is identical in the Python reference code.

Decision boundary and the effect of k

The coloured background evaluates the classifier on a 160 × 120 grid. The colour intensity grows with the fraction of neighbours that agree with the winning class. For k = 1 the regions form a Voronoi diagram of the points and fit noise perfectly; a larger k reduces variance and increases bias. The statistic “Leave-one-out accuracy” classifies each stored point using all other points, which gives an honest estimate that, unlike training accuracy, does not trivially reach 100 % at k = 1.

Practical notes

  • Features should be on a comparable scale, otherwise one coordinate dominates the distance.
  • With many features, distances become less informative (curse of dimensionality).
  • Prediction cost grows linearly with the number of stored points; k-d trees or approximate search reduce it.
