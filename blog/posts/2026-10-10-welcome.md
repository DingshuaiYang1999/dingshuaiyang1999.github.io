## How to write a post

1. Create a Markdown file in `blog/posts/`, e.g. `2026-11-01-my-first-post.md`.
   The file name (without `.md`) becomes the URL: `/blog/2026-11-01-my-first-post.html`.
2. Start it with a front-matter block:

```
---
title: My post title
date: 2026-11-01
tag: Study        # Life, Study or Work
excerpt: One or two sentences shown on the blog index.
draft: false      # optional; true = not published
---
```

3. Write the body in normal Markdown: headings, **bold**, *italic*, lists,
   [links](https://example.com), code blocks, tables and images such as
   `![Alt text](../assets/blog/my-image.jpg)`.
4. Run `python3 tools/build_blog.py`, check the result locally, commit and push.
