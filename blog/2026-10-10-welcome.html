This is an example/template post. It contains no real content. Delete blog/posts/2026-10-10-welcome.md (and re-run python3 tools/build_blog.py) once you have written your first real post.

How to write a post

  1. Create a Markdown file in blog/posts/, e.g. 2026-11-01-my-first-post.md. The file name (without .md) becomes the URL: /blog/2026-11-01-my-first-post.html.
  2. Start it with a front-matter block:
---
title: My post title
date: 2026-11-01
tag: Study        # Life, Study or Work
excerpt: One or two sentences shown on the blog index.
draft: false      # optional; true = not published
---
  1. Write the body in normal Markdown: headings, bold, italic, lists, links, code blocks, tables and images such as ![Alt text](../assets/blog/my-image.jpg).
  2. Run python3 tools/build_blog.py, check the result locally, commit and push.
