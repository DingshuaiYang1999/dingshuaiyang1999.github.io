  1. Example question — how do I add a Q&A entry? (delete me) Website Oct 10, 2026 · asked by Example (template)

    This is an example/template entry, not a real question. Delete qa/entries/2026-10-10-example.md and re-run python3 tools/build_blog.py once the first real answer is published.

    Create one Markdown file per question in qa/entries/ with this front matter:

    ---
question: The question, rewritten so the sender cannot be identified
topic: Study        # e.g. Research, Internship, Study, Other — chips are built from these
date: 2026-11-01
asked_by: A. Student   # optional; leave out to stay anonymous
draft: false           # optional
---

    The body below the front matter is the answer, written in normal Markdown. Only publish questions whose sender ticked "may answer publicly" in the contact form.
